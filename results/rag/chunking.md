# Chunking: structure-aware vs fixed-size

Generated by `python -m coursedeck.rag.ingest`. Both strategies use the bge-m3 tokenizer and `max_tokens=400`; structure merges chunks under 100 tokens with sibling sections, fixed uses a 50-token overlap.

- **cut**: the chunk starts or ends inside a paragraph, list item or table row;
- **multi-section**: the chunk holds content of more than one heading path. Structure chunks merge only small sibling sections and keep their `## heading` lines; fixed chunks mix sections with no marker, so their `section` label is only partly right;
- **headerless table**: table rows without the header row (columns lose meaning).
